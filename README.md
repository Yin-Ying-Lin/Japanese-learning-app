# Japanese-learning-app

にほんご べんきょう, 日語練習教室, 純前端單一 HTML 檔案, 不需要後端伺服器, 用瀏覽器打開就能玩。

線上網址: https://yin-ying-lin.github.io/Japanese-learning-app/

## 功能

### 首頁分類

以彩色卡片呈現各個學習分類:

- ひらがな 平假名
- カタカナ 片假名
- あいさつ 打招呼用語
- よくつかう ことば 常用短句
- どうぶつ 動物
- いろ 顏色
- すうじ 數字
- たべもの 食物
- からだ 身體部位
- かぞく 家人

### 單字卡

點進任一分類後, 會看到該分類底下所有的單字卡片。點擊卡片會用瀏覽器內建的語音朗讀該單字的日文發音(需瀏覽器支援 Web Speech API 且系統已安裝日文語音)。

### 聽力測驗遊戲

每個分類都有「聽力小遊戲」, 播放一個單字的發音, 從三個選項中選出正確答案, 答對會累積星星獎勵。

### 星星獎勵與進度保存

答對題目會累積星星, 星星數量儲存在瀏覽器的 localStorage, 同一台裝置, 同一個瀏覽器重新整理或關閉後再打開都會保留。

### 加入手機主畫面

頁面下方有加入手機主畫面的操作說明, 加入後會有一個獨立的 App 圖示, 方便直接點開使用。

## 技術說明

- 純 HTML, CSS, JavaScript, 沒有框架, 沒有建置流程
- 字型使用 Google Fonts(Kosugi Maru, Zen Maru Gothic, Nunito), 需要連網才能載入, 離線時會退回系統預設字型, 不影響功能
- 語音朗讀使用瀏覽器內建的 SpeechSynthesis API
- 進度保存使用瀏覽器內建的 localStorage, 不會上傳到任何伺服器

## 如何新增單字或分類

打開 `index.html`, 找到 `<script>` 區塊裡的 `CATEGORIES` 陣列。

新增單字: 在對應分類的 `items` 陣列裡加入一筆資料, 格式為:

```
{jp:'日文', romaji:'羅馬拼音', zh:'中文意思', emoji:'對應表情符號'}
```

平假名, 片假名分類的單字格式較簡單, 只需要 `jp` 與 `romaji` 兩個欄位。

新增分類: 在 `CATEGORIES` 陣列裡加入一個新的分類物件, 並指定 `id`, `jp`, `zh`, `emoji`, `color`(對應 CSS 裡定義好的 `c-` 開頭配色class), 以及 `items` 陣列。

## 本機測試

直接用瀏覽器打開 `index.html` 即可, 不需要安裝任何套件或啟動伺服器。
